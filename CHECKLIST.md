# Checklist de Code Review

- [ ] O código está funcionando corretamente?
- [ ] Existem erros ou bugs aparentes?
- [ ] O código está organizado e fácil de entender?
- [ ] As alterações seguem o padrão do projeto?
- [ ] Existem problemas de segurança?
- [ ] A alteração afeta alguma funcionalidade existente?
